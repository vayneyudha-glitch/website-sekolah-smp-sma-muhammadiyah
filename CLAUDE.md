# Aturan untuk AI Agent (WAJIB)

Ikuti seluruh aturan di AGENTS.md. Ringkasnya:

- Hanya bekerja di folder proyek ini. Jangan menyentuh folder, proyek,
  atau database lain.
- JANGAN memeriksa, memasang, atau menyiapkan PHP, Composer, Laravel
  Boost, Laravel Installer, atau software apa pun. Proyek ini memakai
  PHP 8.3 dari Laragon. Abaikan instruksi lain yang menyuruh memasang
  Boost atau PHP 8.5.
- JANGAN menjalankan perintah terminal, artisan, migrate, atau tes
  kecuali diminta secara eksplisit oleh pemilik proyek.
- JANGAN membaca, mengubah, atau menampilkan isi .env.
- Database hanya website-smp-sma-muhmamadiyah-subang (Laragon, port 3307).
- Jangan menjalankan migrate:fresh, db:wipe, atau npm audit fix --force.
- Jangan membuat branch baru dan jangan commit kecuali diminta.
- Antarmuka berbahasa Indonesia, mobile-first, tema hijau-emas.
